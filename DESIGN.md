# Дизайн TWA Classifieds

## Направление и токены

Источник — DESIGN.md, PRODUCT.md и CSS проекта classify-miniapp. Фон #1a2026, поверхности #212a33, вторичные поверхности #293440, кнопки #248bda, ссылки #4db2ff, основной текст #ffffff. Вторичный текст #a1aebb немного светлее исходного для читаемости лендинга.

Шрифт Google Sans Flex совпадает с приложением. Крупный заголовок — 550, короткие строки с плотным интерлиньяжем. Текст преимущественно выровнен влево.

## Композиция

```
Логотип          Навигация               Telegram
Заголовок + CTA              Телефон + объявление + чат
                   Города
Категории и примеры объявлений
Вступление                  Три шага
Преимущества                Объяснения
Выбор города                Районы
Вопросы                     Раскрывающиеся ответы
                   Финальный CTA
```

Главный выразительный элемент — композиция из интерфейса мини-приложения, объявления и личного сообщения. Тонкие орбиты поддерживают идею «рядом». Остальная страница спокойнее: без повторяющихся декоративных анимаций и одинаковых карточек преимуществ.

Структура опирается на qrpayment: первый экран, инструкция, возможности, география, действие в Telegram. Supahero просмотрен как каталог референсов первого экрана; готовые шаблоны не копировались.

## Проверка соответствия брифу

Тёмная палитра продиктована продуктом. Сохраняем локальный контекст и валюту страны. Не используем вымышленные отзывы, метрики, гарантии модерации или безопасности. Все примеры подписаны как демо. Включены четыре активных города из исходного справочника; Тбилиси там закомментирован, поэтому его нет на лендинге.

Изображения сохранены локально в public/images; их Unsplash ID совпадают с исходными моками мини-приложения. Кнопки используют тестового бота из src/telegram/telegram.ts исходного приложения. Адрес настраивается через VITE_TELEGRAM_URL.
