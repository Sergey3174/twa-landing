# TWA Classifieds — лендинг

React 19 + TypeScript + Vite 8 + Tailwind CSS 4.

## Запуск

```powershell
cd C:\Users\Sergey\Desktop\landing_twa\twa_landing
npm install
npm run dev
```

`npm run build` — production-сборка в `dist`. `npm run preview` — просмотр сборки.

## Настройка Telegram

По умолчанию кнопки открывают тестового бота `test_classifyv1_bot`, найденного в исходном мини-приложении. Для замены скопируйте `.env.example` в `.env.local` и задайте `VITE_TELEGRAM_URL`, затем перезапустите Vite или пересоберите проект.

## Что реализовано

- Адаптивный лендинг на русском языке в палитре Fragment исходного проекта.
- HTML/CSS-превью приложения на первом экране.
- Категории, демонстрационные объявления, избранное на время сессии страницы, окно просмотра карточки.
- Переключение городов и районов, FAQ, мобильная навигация.
- Клавиатурный фокус, Escape и возврат фокуса для окна объявления, reduced motion.
- Локальные фотографии и favicon, title, description, theme-color.

Все объявления, фотографии и цены — демонстрационные. Бэкенд не подключён. Фотографии взяты по тем же Unsplash ID, что используются в `classify-miniapp/src/mocks/listings.ts`. Google Sans Flex загружается из Google Fonts; при отсутствии сети используется системный шрифт.

Дизайн: `DESIGN.md`. Основная страница: `src/App.tsx`. Стили и адаптивность: `src/index.css`.

## Проверка

Production-сборка проходит TypeScript и Vite. Автоматическая визуальная проверка в этой сессии недоступна: подключённых браузеров нет. Перед публикацией проверьте внешний вид на телефоне и замените адрес тестового бота, если готов production-бот.
